# Changelog

All notable changes to Arvel Scholar are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-30

### Added

- Bilingual English and French academic website structure.
- Dedicated sections for papers, projects, research questions, resources, and writing.
- Fictional example content and publication metadata.
- Responsive light and dark themes.
- Built-in search and RSS feeds.
- Global social-preview fallback with page-cover priority.
- Optional Cloudflare Workers static-assets deployment.
- Customization, content, deployment, and security documentation.
- Attribution to PaperMod and Pascal Michaillat's Hugo website template.
